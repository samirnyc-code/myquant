**In short:** A TradingView tool that sizes every trade to a fixed **1% account risk** from your entry and stop — so position size is automatic, never guessed.

## Points
- Input account size, entry, and stop → it returns the contract/share size for exactly 1% risk.
- Enforces the core money-management rule (**≤1% risk per trade**) on every setup.

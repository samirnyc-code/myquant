**TL;DR:** Three ways to enter a 50%, always in this order: **(1) First-Test limit → (2) Front-run the 2nd test → (3) Trend-break + next measured move.** "Fade the first test, go with the second."

## 1) First Test — limit, highest probability
- Rest a **limit at the 50%**; the programs' orders sit there too — you grab their coattails.
- **ES:** front-run **+2 ticks**, stop **−6**, first target **+2**, then move stop to **−4** (reduced-risk).
- **Euro:** front-run +4 pips, stop −12, +6 first target → a true free trade.
- **Not filled → pull the order.** A second touch is now a *second* test.
- **Stopped at breakeven → STOP.** Don't re-enter; wait to confirm support is holding, then look for the front-run.

## 2) Front-run the 2nd test — riskiest, best R:R
- Use it if you missed / didn't trust the first test. **"First test safe, second test dangerous."**
- Front-run the prior low/high by 2 ticks, stop 2 ticks beyond (**4 ticks total**), **all-in/all-out, half size** (no reduced-risk here).
- **Stopped out → STOP.** The setup may be failing; wait for the trend break to confirm.

## 3) Trend break + next measured move — the confirmation
- Support isn't **confirmed** until price **breaks the opposing measured move's 61.8%**. Then buy the **first pullback** (trade it with first-test specs).
- This is the safe way in when a first/second test is fighting a **larger opposing setup** — wait for the break.

## Watch-outs
- Bigger opposing setup → don't trust the first/second test; **wait for the trend break**.
- Trend break that **retests the prior high/low first** → skip the pullback (double top). "Whatever trades first."
- **Euro only:** if the 50%↔61.8% distance is < 6 pips, reduced-risk gives no benefit (first target is +6).
